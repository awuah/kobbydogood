HOW TO REPLACE PLACEHOLDER IMAGES
====================================

You can easily replace the placeholder images with your actual high-resolution photos:

1. Member of Parliament Portrait (Hero Section):
   - Replace: `assets/images/hero-mp.svg`
   - File format: JPG, PNG, or WebP
   - Recommended size: 640 x 760 pixels (or similar 4:5 aspect ratio)
   - Update in `index.html`: Change `src="assets/images/hero-mp.svg"` to `src="assets/images/your-mp-photo.jpg"`

2. About Section Photo:
   - Replace: `assets/images/about-kobby.svg`
   - Recommended size: 700 x 520 pixels (4:3 aspect ratio)

3. Project Feature Images:
   - Giving Portal: `assets/images/giving-project.svg` (800 x 500 px, 16:10 aspect ratio)
   - Takoradi Youth Centre (TYC): `assets/images/tyc-project.svg` (800 x 500 px)
   - Kobby's Youth Initiative (KYII): `assets/images/kyii-project.svg` (800 x 500 px)
   - Free Drive Training: `assets/images/freedrive-project.svg` (800 x 500 px)

4. Community Gallery Photos:
   - `assets/images/gallery-1.svg` to `gallery-4.svg` (600 x 420 px)

All images will automatically stay responsive and scale gracefully on all phone, tablet, and desktop screens.
